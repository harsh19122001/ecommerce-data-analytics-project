🛒 E-Commerce Data Analytics Project

This project is a complete Data Analytics workflow project built using Python, SQL, and Power BI to analyze e-commerce sales, customer behavior, payment trends, and market performance.

The objective of this project is to transform raw transactional data into meaningful business insights using data cleaning, exploratory analysis, SQL querying, and interactive dashboards.
